## Built CLI with local Ollama models

Built with `bun build packages/cli/bin/artemis.ts --target bun --outfile <temporary-dir>/akit.js`.
Against the local OpenAI-compatible endpoint, ran each installed local model serially:

```sh
bun akit.js run scenario.yaml --config artemis.config.yaml --model <local-model> \
  --timeout 60000 --retries 0 --ci --summary json --export markdown --export-output ./exports
```

The fixture requested a short response, with temperature 0, maxTokens 48, and regex `[A-Za-z]`.
Each CLI process had a 75-second watchdog. Each model was unloaded after its check. Two inventory
entries marked remote/cloud were excluded; no paid-provider calls or model downloads were made.

For both completed runs, inspected manifests and Markdown exports: requested/observed model names
match, one valid evaluation and denominator one, no invalid/error measurements, workload/rubric
identities present, and cost explicitly unavailable. This prompt-only compatibility fixture has no
tool or policy execution evidence. Tool continuation is separately verified through deterministic
localhost OpenAI/Ling transports and simulated-tool tests; this does not claim live agent capability.

The earlier temporary fixture accidentally escaped the regex and produced valid failed outcomes;
those artifacts were retained and superseded by the corrected runs above. The two 7B timeouts
remain unverified compatibility paths, not passes; their underlying cause was not established.
Local smoke artifacts/logs are temporary machine-local evidence, not committed customer data.

## Remaining boundaries

Single-turn timeout/abort bounds waiting, not in-flight transport cancellation. Tool schemas are
programmer-supplied; synchronous schema compilation is not a CPU sandbox and precedes the wait
deadline. Messages, outputs, and state are working data; only declared bounded evidence summaries
are suitable for retention. Version 1 rejects unavailable environments, custom tools, and policy
fields rather than silently enabling them. No release, deployment, or source push was performed
during the original source-validation checkpoint described above.
