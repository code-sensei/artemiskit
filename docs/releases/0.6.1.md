## Scope

This milestone adds the native multi-turn session engine, CLI workflow execution and preflight,
SDK sessions, fresh simulated state, and a disposable Docker filesystem. The same host boundary
checks declared tools, original arguments, permissions and paths, cumulative budgets, provider
usage, and cancellation/cleanup. Safe saved records contain bounded metadata; sensitive state
export requires an explicit choice.

Independent outcome assertions are retained but not scored: `taskVerification` is `unavailable`.
No durable resume, fault injection, professional workflow report, external integration, arbitrary
command/network capability, or optional third-party harness is included. Historical scenario
execution and report artifacts retain their existing contracts.

See the [execution guide](../workflow-execution.md) for CLI commands, SDK examples, exit semantics,
token limits, Docker requirements, and retention behavior.

## Publication tooling

The maintained publisher handles npm 12 metadata shapes, packs immutable candidates before uploads,
retains candidate/integrity receipts, publishes dependencies before dependants, and reconciles npm's
asynchronous lifecycle before declaring success. Ambiguous uploads are polled rather than blindly
resubmitted. Package and milestone tags follow exact registry/integrity verification.

`--dry-run` implies publish-only and skips version changes, packing, receipts, uploads, and tags;
it still authenticates, installs, checks, and builds. CI repair remains deferred.
