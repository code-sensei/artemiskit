# ArtemisKit 0.5.0 release-validation record

**Release purpose:** establish reproducible workload and rubric identity as the foundation for
defensible assessment evidence and later compatibility checks.

## Scope

- Add manifest v1.2 `workload_identity` with separately versioned workload and rubric digests.
- Canonicalize identity inputs and remove sensitive configuration values and recognized secret text
  before SHA-256 hashing.
- Preserve readability of historical v1.0 and v1.1 manifests without inventing missing identity.
- Document that a digest proves matching sanitized declared inputs, not provider behaviour,
  cryptographic attestation, or comparison eligibility.

## Deterministic validation

| Field | Record |

| Revision | 0.5.0 release candidate; `@artemiskit/core` proposed for minor versioning |

| Runtime | Bun 1.4.2 on macOS arm64 |

| Evidence review | Identity artifacts retain only schema version, algorithm, and digest. They do not retain canonical source material or raw credentials. |

## Release decision

Publication must verify the final package versions, npm dist-tags, package tags, and clean restored
workspace state. Any compatible dependent package bumps are generated by Changesets and recorded
after versioning.
