# ArtemisKit 0.4.1 release-validation record

**Release purpose:** harden v0.4 Evaluation Integrity without changing the
historical manifest contract.

## Scope

- Redact evaluator reason text and bounded evaluator evidence when run redaction is enabled.
- Reject malformed runtime status/evidence fields before standard run manifests are persisted or loaded.
- Retain compatibility for manifests that predate status/evidence fields.
- Provide a strict LLM-judge assurance example.
- Ensure a non-interactive successful package publish does not fail at its final push prompt.

## Release decision

Published packages include `@artemiskit/cli`, `@artemiskit/core`, `@artemiskit/reports`, and
`@artemiskit/sdk` at `0.4.1`; compatible adapter and dependency packages were published at their
corresponding patch versions. Changesets created package tags, including
`@artemiskit/cli@0.4.1`, `@artemiskit/core@0.4.1`, `@artemiskit/reports@0.4.1`, and
`@artemiskit/sdk@0.4.1`.
