# ArtemisKit 0.5.2 release-validation record

**Release purpose:** retain bounded evidence for attempts, retries, repetitions, and costs so
outcome rates and spend claims cannot silently rely on excluded attempts or guessed pricing.

## Scope

- Add manifest v1.4 `attempt_evidence` with stable run, retry-chain, and case-attempt identities.
- Mark whether each terminal attempt is included in the outcome denominator; retries remain visible
  but are not independent measurements.
- Add versioned `cost_provenance`: `known`, `user_supplied`, or `unavailable`. A known cost needs
  provider-billing provenance; local OpenAI-compatible costs are unavailable by default.
- Preserve v1.0–v1.3 manifest readability without inferring new evidence.

## Local-model limitations

The checks used the OpenAI-compatible endpoint at `http://127.0.0.1:11434/v1` through the existing
OpenAI adapter. They do not establish native Ollama-adapter support. The endpoint does not provide
attested provider billing, so these runs explicitly report cost as unavailable and do not claim
local spend.

## Release decision

Git release tags remain unpushed pending separate authorization.
