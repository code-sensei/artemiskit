# ArtemisKit 0.4.2 release-validation record

**Release purpose:** deliver the remaining v0.4 evaluation-integrity hardening as one
customer-facing patch release.

## Scope

- Prove the evaluation-integrity database migration against a disposable PostgreSQL instance,
  including populated legacy rows, backfill, indexes, and integrity constraints.
- Present passed, failed, invalid-measurement, and execution-error outcomes distinctly in the
  CLI and HTML, Markdown, JSON, and JUnit report surfaces.
- Verify npm authentication and ownership before release, using a temporary npm configuration
  rather than persisting the publish token in user-level npm configuration.
