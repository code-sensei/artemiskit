Offline workflow assessment reports are available through the CLI, SDK and reports package.

- Technical, executive and comprehensive views share the same canonical saved V1/V2/V3 evidence.
- Export self-contained HTML or Markdown without credentials, provider calls or task rescoring.
- Findings link to stable evidence pointers and digests. Scope, limitations, policy, target/judge usage, omissions and recovery remain explicit.
- Resume-aware denominators keep historical, preflight, invalid and unavailable evidence separate from eligible task success.
- CLI package allowlisting and publisher path checks exclude local runtime/checkpoint artifacts.
- Bounded regular-file input and exclusive output creation preserve existing files. Legacy scenario reports retain their API.

```sh
akit workflow report evidence.json --output assessment.html
akit workflow report evidence.json --view executive --format markdown --output executive.md
```
